# Engineering Portfolio

> A documentation-first Engineering Knowledge Base built to demonstrate engineering thinking rather than simply showcase projects.

## Overview

This repository contains the source code and documentation for my personal engineering platform.

Unlike a traditional portfolio, this project is designed as a connected knowledge base where engineers can explore backend engineering, system design, cloud, security, and software architecture through articles, engineering logs, and real-world case studies.

The goal is simple:

> Build a platform that teaches *how an engineer thinks*, not just *what an engineer has built*.

## Philosophy

This project follows a documentation-driven development approach.

Every architectural, design, and product decision is documented before implementation.

Documentation is treated as the source of truth, while code is the implementation of those decisions.

---

## Documentation

Project documentation is available in the `/docs` directory.

It is organized into three phases:

### Phase 1 — Strategy

Defines why the platform exists and what it aims to achieve.

### Phase 2 — Design

Defines the visual language, interaction principles, and reusable component system.

### Phase 3 — Engineering

Defines the technical architecture, content model, and implementation roadmap.
